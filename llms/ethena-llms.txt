# Ethena API

> Ethena is a compliance platform powered by AI agents that helps organizations manage employee training, disclosures, policy, third-party risk, and ethics reporting for 2,000+ organizations. The Ethena API lets you view and manage learners and training information, and subscribe to webhooks for training-completion events. Authentication is HTTP Basic using an API key provisioned by an Ethena representative. This llms.txt was generated by the API Evangelist enrichment pipeline from Ethena's public OpenAPI definition.

## APIs
- [Ethena API (OpenAPI 3.1)](https://api.goethena.com/docs/ethena-openapi.yaml): Learners, training campaigns, learner training campaigns, learner training modules, and webhooks. Base URL https://api.goethena.com, all operations under /v1/.
